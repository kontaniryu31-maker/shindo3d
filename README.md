# 3D 自由進度表 ポータル

「すすむ × ふかめる × つなげる」の3軸でつくる自作教材「3D自由進度表」のポータルサイトです。
トップページ（`index.html`）から各教科の単元へ移動できます。

## 収録単元

| 教科 | 単元 | パス |
|---|---|---|
| 算数3年（東京書籍） | たし算とひき算の筆算 | `/sansu/` |
| 社会3年（青葉出版・奈良市版） | わたしたちの奈良市（方位・地図記号） | `/shakai/` |
| 理科3年（啓林館） | 生きものの育ちとつくり（たね・植物・チョウ） | `/rika/` |

## 特徴

- **すすむ**（ステージ横軸）× **ふかめる**（読む→つかう→せつめい→高め合う）× **つなげる**（前後の単元）の3D表示
- 各マスに「クリア条件」「つかうどうぐ・リンク（NHK for School 等）」「無限れんしゅう問題」「探究タイム」
- 進度（色ぬり）は端末の localStorage に自動保存
- 単体HTML（React 18 + Babel standalone, CDN読み込み）。ビルド不要

## 設計思想

けテぶれ・QNKS・SRL（自己調整学習）をベースにした、子どもが自分のペースで進める自由進度学習ツール。
